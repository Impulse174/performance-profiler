# Changelog Performance Profiler

## [2.0.0] - 2026-03-30

### 🎯 Major Improvements

#### Полная переработка архитектуры
- **PerformanceProfiler** - рефакторинг ядра с использованием контекстных менеджеров
- **ProfileMetrics** - новая dataclass структура для типизированных метрик
- **Config system** - централизованное управление конфигурацией через `config.py`

#### Улучшения производительности
- Контекстный менеджер `_profiling_context()` для гарантированной очистки ресурсов
- Автоматическое управление `tracemalloc` с корректной обработкой ошибок
- Оптимизация работы с GC - сборка мусора перед замерами

#### Type Safety
- Полные type hints для всех публичных API
- Dataclass для метрик вместо "голых" словарей
- Строгая типизация конфигурации

### ✨ New Features

#### Анализ алгоритмической сложности (AST)
- `_analyze_time_complexity()` - анализ временной сложности через подсчет циклов
- `_analyze_space_complexity()` - анализ памяти по структурам данных
- Поддержка вложенных циклов и comprehensions

#### Конфигурация
```python
from config import update_config, get_config

update_config(
    log_level="DEBUG",
    max_result_length=2000,
    analyze_complexity=True
)
```

#### Улучшенный CLI
- Красивый вывод с emoji и разделителями
- Поддержка коротких флагов (`-f`, `-k`)
- Валидация аргументов и понятные ошибки
- Форматирование больших результатов

### 🔄 Breaking Changes

#### Для пользователей v1.x

1. **Изменен импорт конфига:**
   ```python
   # Было:
   from performance_inspect import profiler
   
   # Стало:
   from performance import auto_profile
   from config import update_config
   ```

2. **Новая структура метрик:**
   ```python
   # Вместо словаря теперь dataclass:
   metrics.execution_time  # а не metrics['execution_time']
   ```

3. **Обновлен CLI:**
   - Требуются явные аргументы
   - Изменен формат вывода

### 🎯 Migration Guide

Для перехода на v2.0:

1. Обновите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Проверьте совместимость:
   ```bash
   python -m pytest tests/test_profiler.py -v
   ```

3. Обновите код если использовали прямой доступ к метрикам:
   ```python
   # Старый стиль:
   metrics['execution_time']
   
   # Новый стиль:
   metrics.execution_time
   ```
